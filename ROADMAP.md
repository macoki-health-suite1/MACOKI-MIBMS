# Roadmap
1. Stabilize local inventory and transactions; add editing, returns, stock adjustment and CSV/PDF exports.
2. Implement server authentication, business memberships, permissions and strict tenant/branch queryset filtering.
3. Implement transactional purchase/sale services, payment records, immutable stock ledger and idempotency.
4. Connect frontend to API; define offline outbox, retry, sync cursor, conflict UI and reconciliation.
5. Implement accounting ledger (double entry), cashbook, bank accounts, receivables/payables aging, trial balance, P&L and balance sheet.
6. Add PWA service worker and Android packaging; test offline launch and app upgrades.
7. Add audit logging, backup/restore, monitoring, security review and controlled pilot.
8. Conduct user acceptance testing across pharmacy, retail, wholesale and general-business workflows.
